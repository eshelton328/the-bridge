Like the Claude desktop app, the folders control sits in the row under the prompt box, beside the model (R45). It shows the working folder and how many more there are, and opens a list: the working folder, folders added since, and Add folder, which opens the picker on the right. The + button next to the prompt box offers Add folder too, next to attachments. The controls are the same for both kinds of chat. Underneath, a Claude Code chat gets the folder at once through /add-dir; Codex CLI 0.169.0 has no such command, so the-bridge resumes the session with codex resume --add-dir (proposed; see open question 16).
