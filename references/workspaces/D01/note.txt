Split panes are desktop only (R19). Cmd+D splits a pane and dragging a chat from the sidebar opens it in a new one (D6); whether each workspace keeps herdr's own layout is open question 4. Workspace tabs switch workspaces. Drag a tab to reorder it (R7); The + after the tabs starts a new chat in the current workspace, as in herdr (R9). A tab's menu renames or closes its workspace; new workspaces are created from the sidebar, as in D2 (R6). Each pane's menu forks the chat, opens a side chat, starts a subtask or moves the chat to another workspace (R8, R10, R11, R25). Typing / lists the skills (R13); Stop cancels the running prompt (R15). The sidebar button at the top left opens the workspace sidebar, as in D2. A rail on the left, on every desktop frame, holds the Span mark (Home), Inbox, Workspaces, Projects and More: the same places as the phone and iPad tab bar. It stays visible in a chat, since the desktop has room.
