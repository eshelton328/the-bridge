The map shows the toolkit (R36): one column for each kind, and a line where one file links to another. When writer is selected, its 11 lines light up and the items it does not touch go dim. Which links the map should show is requirements open question 12; these lines are file links only. Show on map on an item page opens this view with that item selected. The Links tab (D19) shows only the item’s own links, with the file and line of each.
