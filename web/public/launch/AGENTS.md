# web/public/launch

The iOS startup images: renders of index.html's launch view (`#launch`),
one for each device, orientation and colour mode that `index.html`'s
`apple-touch-startup-image` links name. Never edit one by hand; read
[../AGENTS.md](../AGENTS.md) for how to render them again, and run
`src/app/launchImages.test.ts` after.
