# Artifacts library gaps

(`@eshelton328/component-library-1701`, `1.0.0-beta.74` in this worktree)
cannot draw. Each gap goes to the library in one batched PR (fidelity
loop, step 2). Until then the screen uses the part named under "Used
now", and the frame's `deviations.md` lists the difference.

50 px high and 56 px apart, as Figma's, in every frame D1 to D9. Library
#121 (beta.19) closed the icon-only view switch and the Sort menu rows;
see "Closed by 1.0.0-beta.19" under the table. Library 1.0.0-beta.36 closed
the row previews' sizes and drew the phone's New badge; see "Closed by
1.0.0-beta.36". Library #147 (beta.39) closed the desktop list rows'
padding and the New dot in a list row; see "Closed by 1.0.0-beta.39".

see "Closed by 1.0.0-beta.42". Library 1.0.0-beta.47 closed the phone's
New badge size and its place in a search row; see "Closed by
