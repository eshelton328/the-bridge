# Workspaces library gaps

Parts and tokens the Workbench frames (Figma page 89:2) need that the
component library (`@eshelton328/component-library-1701`, the build
installed in this worktree, `1.0.0-beta.15`) cannot draw. Each gap goes to
the library in one batched PR (fidelity loop, step 2). Until then the
screen uses the part named under "Used now", and the frame's
`deviations.md` lists the difference.

## Closed by 1.0.0-beta.15

- **Sidebar toggle** (D01, D05): `Workbench` has `leading`, before the
  tabs; the toggle sits there, where Figma draws it (158:2, 158:119).
- **Submenu** (D01): `MenuAction.submenu` opens Move to workspace's list
  200 wide to the right of the row, at its top (105:473). The list's box
  takes no `data-figma` (Submenu data attributes, above).
- **Menu highlighted row** (D01, D02b): `Menu` and `MenuSubmenu` take
  `highlightedValue`; the states fill Move to workspace and, in D01,
  the-bridge, and `density="compact"` draws the highlighted row's icon in
  `fg.accent`, as Figma does.
- **ContextMeter percentage** (D01 to D07): `ContextMeter` draws the
  percentage as one text node, so the text check finds "42%" and the
  others without an exception.
