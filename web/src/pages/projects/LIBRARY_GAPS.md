# Projects library gaps

Parts and tokens the Projects home (f-008 increment one, d-133) needs that
the component library (`@eshelton328/component-library-1701`,
`1.0.0-beta.135` in this worktree) cannot draw. Each gap goes to the
library in a batched PR through the `library-gap-filler` agent. Until it
ships, the page uses the part under "Used now", and each frame's
`deviations.md` lists the difference. The frames are PNG references
(`references/projects/`), so no Figma node of the library file is named.

| Part or token                                         | Frames         | What is missing                                                                                                                                                                                                                                                                                                             | Used now                                                                                                         |
| ----------------------------------------------------- | -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Pin icon                                              | D10, T10, T10b | The pin after a pinned project's name. The library has no pin icon.                                                                                                                                                                                                                                                         | `Badge variant="pill" size="xs"` (16 high, inside the name's line) with the label "Pinned" as the card's `badge` |
| Project tile (letter or icon on the card's media)     | D10, T10, T10b | A media tile with the project's letter (about 40 px, SemiBold, `fg.muted`) or icon, at the frames' height: about 204 px on a desktop or tablet card. No size or text token has those values.                                                                                                                                | `ProjectTile`: `surface.well`, `py` 40 (32 on the phone), letter in `heading`                                    |
| Card description with every line, or a set line count | D10, T10, T10b | `Card`'s `description` shows one line at Small or exactly two (`descriptionLines`). D10 and T10 show the whole purpose; T10b cuts it at three lines.                                                                                                                                                                        | The purpose as a `bodySm` paragraph in the card's `meta` row                                                     |
| Card grid columns by width                            | T10b           | T10b draws three columns at 1133 px, in the tablet layout. `Grid` takes a fixed column count, and no token gives a card's least width.                                                                                                                                                                                      | `Grid` with four columns on the desktop, two on a tablet, one on a phone                                         |
| Purpose text style (13/20, wider tracking)            | D10, T10, T10b | The frames set the purpose at 13 px on a 20 px line, with glyphs about 4 % wider than `bodySm` (Geist 13/20, no tracking): "A Chrome extension that pins comments on" is about 268 px in D10 and 259 px in `bodySm`. That fits 13 px with about 0.26 px letter spacing; no text style has it, and `body` (14/20) is 279 px. | `bodySm`; the purposes break at other words (each frame's `deviations.md`)                                       |
