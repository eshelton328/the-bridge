# Toolkit library gaps

Parts and tokens the Toolkit frames need that the component library
(`@eshelton328/component-library-1701`, the build installed in this
worktree) cannot draw. Each gap goes to the library in a batched PR
through the `library-gap-filler` agent; bridge-coord releases it
(d-104). Until then the screen uses the part named under "Used now", and
the frame's `deviations.md` lists the difference.

Library #115 (beta.14) closed the rail item height (`NavRail` items 50 px
high and 56 px apart, as Figma's) and the More drawer's item spacing (M04's
four item icons pass the position check). The workspace installs
`1.0.0-beta.18`.
